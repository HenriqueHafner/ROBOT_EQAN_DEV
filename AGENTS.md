# Project Coding Guidelines for AI Assistants

This project uses AI tools primarily for software development.

## Core Rules

- Be clear and keep one operation per line when possible.
- Always use `snake_case` for variables, functions, and file names.
- Avoid comments and docstrings. Use descriptive variable and function names to explain the code.
- Give concise and direct answers.
- Use normal text for conversation. Use code blocks only for code snippets or scripts.

## Readability Priority

Prefer multiple clear, intelligible lines over conciseness or micro-optimizations.

- Write code that is easy for the whole team to understand.
- Avoid nested loops when possible.
- Favor readability and maintainability even if it increases line count.

## Communication Style

- Be direct.
- Do not over-explain unless asked.
- Separate discussion from code using code blocks.
